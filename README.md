# Учимся с компьютером

Сайт с уроками для ребёнка: Windows, Word, Excel, PowerPoint, Outlook и ИИ. Чистый HTML, без сборки.

Кроме уроков есть два отдельных теста: входной (`entry.html`) подсказывает, с чего начать, итоговый (`final.html`) проверяет все миры. Прогресс уроков они не меняют, вопросы лежат прямо в этих файлах, общий движок — `exam.js`.

## Как посмотреть локально

Открой `index.html` двойным кликом. Всё работает без сервера.

## Как добавить урок

1. Добавь строку в список `LESSONS` в `lessons.js` (порядок в списке = порядок уроков).
2. Скопируй любой файл из `lessons/`, назови по id (например `lessons/w8.html`), поставь `data-lesson="w8"` в `<body>`.
3. Напиши текст и вопросы теста в блоке `quiz-data` (`right` — номер правильного ответа, считая с 0).

Картинки и скриншоты клади в папку `img/` и вставляй так: `<img src="../img/name.png" alt="...">`.

Схемы-иллюстрации (`img/*.svg`) рисует скрипт `tools/schemes.py`: поправил координаты или текст — запусти `python3 tools/schemes.py`, и все картинки перерисуются.

